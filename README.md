# 故事成歌（story-to-song）

给零基础的人用的中文写歌 skill：从一个故事或一句想说的话，到一首能写进 Suno / 海绵音乐的歌词和提示词。一个 skill 走完，不需要懂乐理，也不需要会写词。

## 安装

**方法一：一行命令**（电脑上需要有 Node.js）

```
npx skills add yyue5578-coder/story-to-song
```

按提示选择要装到哪个 agent（Claude Code、Codex、Cursor 等）即可。

**方法二：手动下载**

1. 点本页右上方绿色的 **Code → Download ZIP**，解压。
2. 把解压出来的文件夹改名为 `story-to-song`。
3. 放进你的 agent 的 skills 目录，例如：
   - Claude Code：`~/.claude/skills/`
   - Codex：`~/.codex/skills/`
   - WorkBuddy：`~/.workbuddy/skills/`

装好后直接对 agent 说「我想写首歌」「帮我写首歌给我妈」就会触发。

**可选：歌词校验脚本**

`scripts/check_lyrics.py` 用来检查押韵、句长、AI 味和多音字读音，需要 Python 3；读音检查还要先装 pypinyin：

```
pip3 install pypinyin
python3 story-to-song/scripts/check_lyrics.py 歌词定稿.md --min-rate 0.6
```

不装也能用，写词流程照常走，只是少了自动检查这一步。

## 能做什么

1. **提问**：按场景和感觉问，一次最多 3 个问题；用户没有具体事件时问小碎片，不替用户编。
2. **核实事实**：写真人真事时联网查证，事实分三档（多源一致 / 单一来源 / 互相矛盾）。
3. **写词**：先定场景、80 字方向确认、规划韵脚，再逐段写。
4. **校验**：`scripts/check_lyrics.py` 检查押韵、句长、字数、AI 味、多音字读音风险。
5. **打磨**：主动指出可能不像人话的句子，按用户反馈只改被指的地方。
6. **出提示词**：Suno 和海绵音乐，先问男声还是女声，不按姓名推断性别。
7. **生成后检查**：只听三处，只局部重做。

## 覆盖的场景（`knowledge_base/`）

怀念/释怀、暗恋/心动、生日/祝福、纪念/求婚、道歉/感谢、亲情。6 份场景规律，来自 38 首歌的拆解。**每份场景规律顶部写明可信度**，样本不足的场景会告诉用户。

38 首单曲拆解只留在作者本机，本仓库不附带（skill 不依赖它们）；场景规律里写到“单曲文件”处，指的就是那批本地文件。

## 目录

```
story-to-song/
  SKILL.md             工作流入口
  references/          写词规则、提问、打磨、迭代、Suno、海绵音乐、生成后检查
  knowledge_base/      场景规律、配比统计、说明（单曲拆解不附带）
  scripts/             check_lyrics.py（需要 Python 3；读音检查用 pypinyin）
  templates/           创作注解模板、单曲拆解模板
```

## 提醒

- 写真人真事的歌，要标"粉丝二创 / AI 辅助创作"，不替当事人下结论、不编对方的心理和原话。
- 场景规律依据的单曲背景信息（作曲人、发行日期、获奖年份等），部分来源之间有冲突，作者本机的单曲文件里已标注“未核实”。
- 配比区间来自早期 17 首样本，是一遍人工分类，只当参考。
- 海绵音乐的提示词细节尚未实测。
